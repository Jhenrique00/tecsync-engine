TECSYNC ENGINE — ATUALIZAR SEM PERDER DADOS

1. Encerre a execução atual com Ctrl+C.
2. Faça um backup protegido da instalação, incluindo dados locais e configurações.
3. Atualize o código preservando .local e .env.
4. Execute npm run setup, npm run build e npm start.
5. Acesse http://127.0.0.1:8000 e verifique seus dados.

Não apague .local/master.key: sem ela, credenciais antigas não podem ser decifradas.
Não publique backups, bancos, chaves ou arquivos .env.
Consulte README.md antes de executar. Não direcione testes para produção.
